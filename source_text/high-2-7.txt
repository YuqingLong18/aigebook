2.7 Typical Neural Network Structures 

Learning Objectives 

(1) Understand the basic concepts of four typical neural network structures (MLP, CNN, RNN, AE), and clarify their respective applicable tasks and characteristics. 

(2) Grasp the working principle of the Multilayer Perceptron (MLP), and understand the characteristics and application scenarios of fully connected neural networks. 

(3) Understand the structure and characteristics of the Convolutional Neural Network (CNN), and master the basic principles of convolution operations and pooling operations and their advantages in image processing tasks. 

(4) Understand the core mechanism of the Recurrent Neural Network (RNN), master its application principles in tasks such as time series and natural language processing, and clarify the role of its memory characteristics. 

(5) Understand the structure and basic uses of the Autoencoder (AE), and master its feature extraction and data generation capabilities. 

Shape 

Artificial neural networks have very flexible structures. Different structures have different characteristics and are therefore suitable for different tasks. This section will introduce four representative neural network structures: Multilayer Perceptron (MLP), Convolutional Neural Network (CNN), Recurrent Neural Network (RNN), and Autoencoder (AE). Understanding the basic assumptions behind these special structures can give us a deep understanding of the network's characteristics, allowing us to choose the appropriate network for different tasks. 

 

Multilayer Perceptron 

The Multilayer Perceptron is an extension of the standard perceptron proposed by Rosenblatt. A typical Multilayer Perceptron consists of at least three parts: an input layer, a hidden layer, and an output layer. 

Figure 2-49 shows a multilayer perceptron with 3 layers. Data is first fed into the network through the input layer and is multiplied by connection weights before being passed to the hidden layer nodes. The hidden layer nodes will sum these weighted inputs and obtain an activation value through a nonlinear function. These activation values from the hidden nodes are again weighted, summed, and then passed to the output layer. 

Generally speaking, all nodes in two adjacent layers of a Multilayer Perceptron are interconnected, so it is also called a fully connected neural network. Theoretically, there is no limit to the depth (i.e., the number of layers) of a Multilayer Perceptron; networks of any depth can be trained using the backpropagation algorithm. The Multilayer Perceptron is the most general network structure, and other network structures can be seen as specializations of it. However, this does not mean the Multilayer Perceptron is the best. This is because data from different domains often has domain specificity (refer to the discussion on "knowledge" in Section 2.3), and constructing structurally unique networks that consider these specificities will usually achieve better results. 

 

Convolutional Neural Network 

The Convolutional Neural Network is one of the most widely used neural networks with a special structure today. Unlike a fully connected neural network (MLP), each neuron in a Convolutional Neural Network is only connected to a portion of the neurons in the previous layer, and neurons at different positions share the same connection weights. These shared weights are called a "convolutional kernel." The following uses a two-dimensional Convolutional Neural Network as an example to illustrate its computation process. In this structure, the neurons in each layer are arranged on one or more two-dimensional planes, with each plane called a "feature map" or a "channel."

The computation process of a Convolutional Neural Network is similar to a "lens" scanning across the input plane; the parameters of this lens are the convolutional kernel. This process is very close to the mathematical operation of convolution, which is why this type of network is called a Convolutional Neural Network. 

This scanning process can be understood as a feature extraction process, and what features are extracted is determined by the convolutional kernel. The values on the output plane can be understood as the likelihood that the feature represented by the convolutional kernel is detected at the corresponding position on the input plane. Figure 2-51 illustrates the basic workflow of a convolution operation. The diagram shows the input plane (or input feature map) on the left, the convolutional kernel (or filter) in the center, and the output plane (or output feature map) on the right. The convolutional kernel scans the input plane from top-left to bottom-right. The spatial interval between each scan is called the stride. If the stride is 1, methods like zero-padding the borders can be used to keep the output and input planes the same size. 

 

If the input contains multiple channels, a three-dimensional convolutional kernel can be used. During computation, it scans multiple input channels simultaneously to extract combined features, as shown in Figure 2-52. In this way, simple features can be combined into complex features. For example, simple features like lines and corners can be extracted in the first layer, and in the second layer, these can be combined into more complex features like triangles and hexagons through three-dimensional convolution. 

 

In addition to convolution operations, Convolutional Neural Networks also include pooling operations, which "compress" several neighboring neurons into a single one. "Average pooling" and "max pooling" are the two most common types of pooling operations, which extract the average and maximum values of neighboring neurons, respectively. Pooling can also be viewed as a special type of convolution, except that the convolutional kernel is fixed. Therefore, terms from convolution operations like channel, pool size, and stride can be used to describe it. Figure 2-53 shows a max pooling process with [Equation] pools and a stride of 2. 

 

If the stride of the pooling layer is greater than 1, the activation plane will be compressed by a factor equal to the stride. If a convolutional kernel of the same size is then used for feature extraction, it means the kernel's field of view (usually called the "receptive field") has been enlarged. For example, after compression by a pooling layer with a stride of 2, a [Equation] convolutional kernel is actually looking at a [Equation] block of data. This means the convolutional kernel is extracting features on a larger scale. 

 

When multiple convolutional layers and pooling layers are connected in series, features are extracted through convolution on one hand, while the scale of the features is expanded through pooling on the other, resulting in increasingly complex and abstract features. As illustrated in Figure 2-54, for example, in the deeper layers of the network, the convolutional kernels will extract a human face instead of a blob of pixels, or the shape of flowers and birds instead of simple light, shadows, and lines. This hierarchical feature extraction ability is an important reason for the success of deep learning. 

 

Convolutional Neural Networks are particularly suited for processing data that has local features and where these features exhibit spatial invariance. For example, when observing a picture containing a cat's face, you can see that the cat's face only occupies a part of the entire image, so the cat's features are local. At the same time, no matter where the cat's face is in the picture, it is still a cat; this is the so-called spatial invariance, as shown in Figure 2-55. 

 

The Convolutional Neural Network is designed based on these characteristics of images. Because features are local, modeling only needs to consider local connections, so it is feasible to use small-scale convolutional kernels to capture these local features. Because features have spatial invariance, the same convolutional kernel can be shared across different positions for feature extraction. 

 

Recurrent Neural Network 

A Recurrent Neural Network is a type of neural network with recurrent connections. This special connection allows the network to handle tasks related to time series. As shown in Figure 2-56, The hidden layer of a Recurrent Neural Network includes a recurrent connection to itself. It is worth noting that due to the recurrent connection, the value of the hidden layer node from the previous time step is passed to the next time step. Therefore, the network's behavior at each moment is not independent but depends on its previous states. In other words, an RNN has memory capability, and its output has a cumulative temporal effect.

Based on this memory characteristic, Recurrent Neural Networks are particularly suitable for handling tasks where sequence order is important. For example, in language understanding, the order of words is crucial; "Wu Song beats the tiger" and "The tiger beats Wu Song" have completely different meanings, and "I love learning" is also different from "Learning loves me." A Recurrent Neural Network can accumulate semantic information through its recurrent connections, thus correctly understanding sentences with different word orders.

Figure 2-58 demonstrates how a Recurrent Neural Network can be used to predict the sentiment of a sentence by summarizing the meaning of each word. If a sentence contains a word indicating positive sentiment like "like," the network will ultimately output a strong positive sentiment. 

 

Autoencoder 

The Autoencoder is another special neural network structure whose training objective is to make the network's output as consistent with the input as possible, that is, to reconstruct the input data. As illustrated in Figure 2-59, if the input data is a cat, the network's goal is to reconstruct this cat as accurately as possible at the output. 

The special feature of an Autoencoder is that the number of nodes in the middle layer of the network is less than the number of nodes in the input and output layers; this layer is called the bottleneck layer. Because the bottleneck layer only allows a small amount of information to pass through, it must represent only the most important information to reconstruct the input data. Therefore, an Autoencoder naturally has the ability to extract important features. In Figure 2-59, the bottleneck layer might retain a subject's outline, as this is the most crucial information for reconstructing the original input image. 

An Autoencoder can learn the important features in data. When these features are adjusted, the characteristics of the generated data can be changed. Figure 2-60 demonstrates that after learning from car images, the bottleneck layer can extract typical features of a car. When these features are adjusted, different types of cars can be generated. 

 

Section Summary 

This section introduced four typical neural network structures: Multilayer Perceptron (MLP), Convolutional Neural Network (CNN), Recurrent Neural Network (RNN), and Autoencoder (AE). Each network structure has its unique design features and scope of application. 

Convolutional Neural Networks, through local connections and weight sharing, are particularly suitable for processing data with local features and spatial invariance, such as images and videos. Recurrent Neural Networks excel at temporal modeling and are suited for tasks related to time series, like language translation and speech recognition. Autoencoders can extract important features from data and remove redundant information through a bottleneck layer. 

These special neural networks can all be viewed as special cases of the Multilayer Perceptron model. Theoretically, the Multilayer Perceptron model has greater freedom and stronger learning ability. However, when applied to practical problems, these models with special structures usually perform better. This is because these models all incorporate some basic assumptions in their design. When the characteristics of the data satisfy these assumptions, the model and the data have a high degree of compatibility, making learning easier. This is also the reason we repeatedly emphasize domain knowledge when introducing machine learning methods: designing more suitable models based on domain knowledge can greatly improve the efficiency of machine learning. This is one of the most important methodologies in the field of machine learning.
